# 03 · 渠道选项详解（递延模式、港清 vs 监管仓）

> 清关渠道不是"选最便宜的"——不同渠道有**不同的申报比例、不同的查验率、不同的适用品类**。选错渠道，轻则成本高，重则查验扣货。

---

## 核心概念：港清 vs 监管仓清关

所有渠道可以归为两大类，理解了这个根本区别，渠道选择就有了框架：

| | 靠港清关（Port Clearance） | 监管仓清关（Bonded Warehouse Clearance） |
|---|---|---|
| 流程 | 船到港 → 申报 → 海关放行 → 提柜 | 船到港 → 进监管仓 → 申报 → 海关放行 → 提柜 |
| 费用 | 省监管仓费 | 多了监管仓存储 + 操作费 |
| 灵活性 | 需在港期内完成申报 | 申报窗口更宽 |
| 时效风险 | 赶不上就只能选监管仓方案 | 赶不上也没事 |

## 核心概念：逆算申报 vs 固定申报

| | 逆算申报 | 固定申报 |
|---|---|---|
| 逻辑 | 根据合理的利润倒推申报价格，比例区间申报 | 按链接价的固定下限起步申报 |
| 比例区间 | 20%-40% | 30% 起 |
| 适合 | 单价跨度大、价格波动大的产品 | 钢铁制品、无 MTC 文件的货等 |
| 风险 | 申报比例偏离数据库平均价时触发预警 | 固定比例本身就是行业共识，相对安全 |

## 核心概念：VAT 递延 —— 为什么选递延

**Duty（关税）vs VAT（增值税）是两种完全不同性质的税：**

| | Duty（A00 关税） | VAT（B00 增值税） |
|---|---|---|
| 性质 | "过路费" | "销售税" |
| 征收时点 | 进口时必须支付，**不能递延** | **可以递延**至销售后申报 |

### 为什么选择递延

1. **资金效率**：仅缴纳关税，增值税递延，大幅降低资金占用
2. **合规性**：提供完整进口申报记录，保护电商平台账号
3. **清关独立性**：单票申报，不受其他货物影响

## 四种主流清关渠道详解

> 以下四种渠道是跨境电商物流行业中最常见的"递延模式"渠道。不同清关行会给它们起不同的内部代号，但其底层属性就是以下四种的排列组合。

### 渠道 A：港清 + 固定申报（低税率品类适用）

| 项目 | 描述 |
|---|---|
| 清关点 | 荷兰为主 |
| 清关方式 | 靠港清关 |
| 申报方式 | 固定申报，比例 28%-35% |
| 适用品类 | 玩具、灯具、纺织品 |
| VAT 递延 | ✅ 需资质 |

### 渠道 B：港清 + 逆算申报（单价跨度大适用）

| 项目 | 描述 |
|---|---|
| 清关点 | 荷兰为主 |
| 清关方式 | 靠港清关 |
| 申报方式 | 逆算申报，比例 20%-40% |
| 适用品类 | 单价跨度大的产品 |
| VAT 递延 | ✅ 需资质 |

### 渠道 C：监管仓 + 固定申报（需 MTC 豁免）

| 项目 | 描述 |
|---|---|
| 清关点 | 荷兰 / 比利时 |
| 清关方式 | 监管仓清关 |
| 申报方式 | 固定申报，比例 28%-35% |
| 适用品类 | 钢铁制品、无 MTC 文件的货 |
| VAT 递延 | ✅ |

### 渠道 D：铁路 + 监管仓（高查验率）

| 项目 | 描述 |
|---|---|
| 清关点 | 比利时为主 |
| 清关方式 | 监管仓清关 |
| 申报方式 | 固定申报，比例 28%-35% |
| 适用品类 | 铁路运输的整柜货 |
| VAT 递延 | ✅ |
| ⚠️ 额外风险 | 玩具/灯具/纺织品查验率极高 |

## 各国 VAT 递延政策对比

| 国家 | 是否支持递延 | 特殊要求 |
|---|---|---|
| 英国 | ✅ 支持 | 有 VAT + EORI 即可（PVA） |
| 比利时 | ✅ 支持 | 需 ET14.000 许可证 |
| 荷兰 | ✅ 支持 | 需"第 23 条许可证" |
| 德国 | ✅ 支持 | 只允许提供银行担保的企业延迟支付 |
| 法国 | ✅ 支持 | 企业需在法国缴纳增值税 |
| 意大利 | ❌ 不支持 | — |
| 西班牙 | ⚠️ 限制 | 只允许大型企业使用 |

## 渠道选择决策树

```
你的货物是什么品类？
├── 玩具/灯具/纺织品 → 查 04_product_matrix 推荐的入境点
│   └── 时效要求高？ → 渠道 A（港清 + 固定申报，荷兰）
│   └── 单价跨度大？ → 渠道 B（港清 + 逆算申报，荷兰）
├── 钢铁制品 / 无 MTC → 渠道 C（监管仓 + 固定申报）
├── 高货值电器 → 查 04_product_matrix
└── 铁路运输 → 渠道 D（比利时监管仓，注意查验率）

你的货物有合规资质吗？
├── CE / EN71 / ERP / MTC 齐全 → 可选范围大
└── 资质不全 → 重新审视品类选择，考虑改包税渠道
```
